# E2 calibration (S3, 2026-09-24)

This note freezes the E2 thresholds (SPEC §8.3) against this repo's own tuning fixtures: the six known-bad games in `fixtures/known-bad/` and the four good controls in `fixtures/good/`. It lists only tuning fixtures. Holdout fixtures are written after this note and are never used to set a value here (SPEC §9.3).

**What these numbers are.** Each figure is a measurement of a hand-authored fixture, taken with `node src/eval/cli.ts matrix` in headless Chromium (Playwright 1.63.0, Windows 11, four runs on 2026-09-24). They show the margin between each fixture and each threshold. They say nothing about how often a generated game has these defects, and no detection rate is claimed.

## Research: does Playwright see errors from the sandboxed frame?

SPEC §8.1 asked whether `page.on("pageerror")` sees errors raised inside the `sandbox="allow-scripts"` srcdoc iframe. Measured with Playwright 1.63.0 and its bundled Chromium: yes for uncaught exceptions and unhandled rejections (both surfaced as `pageerror`), while `console.error` surfaces only as a `console` event of type `error`. The probe still relies on its own injected forwarder (`src/eval/e2/instrument.ts`), which reports all three kinds through the host page; `tests/eval/e2/probe.test.ts` pins both observations so a Playwright upgrade that changes either one fails a test.
